## About

Movement Plus is a mod that adds a couple of additional movement options, primarily midair jumps and coyote time. All of this mods features can be configured to fit your preferences.

Available for **NeoForge** and **Fabric**. Requires [Architectury API](https://modrinth.com/mod/architectury-api); on Fabric additionally [Fabric API](https://modrinth.com/mod/fabric-api) and [Forge Config API Port](https://modrinth.com/mod/forge-config-api-port).

Features:

* Multi Jumps
* Coyote Time
* Adjustable jump power
* Adjustable step height
* Adjustable movement speed
* Adjustable swimming speed
* ... more to come!

Most of these features are inactive by default and must be enabled in the server config, either through the in-game config screen or in the `config` folder. Midair jumps, coyote time, and swim speed are also available as player attributes, so equipment and other mods can grant them dynamically.

## What is Coyote Time

Coyote time is a short time frame during which the player can jump even if they technically already ran of the edge of the block. It's a small grace period if you mess up your jump so to say.

But it's also useful if you try to go down stairs and jump off them or situations like that where vanilla Minecraft's jump mechanics are usually a pain in the bum.

The default length of coyote time in this mod is 3 ticks or a bit more than a tenth of a second. So it's there but shouldn't be too noticeable.
